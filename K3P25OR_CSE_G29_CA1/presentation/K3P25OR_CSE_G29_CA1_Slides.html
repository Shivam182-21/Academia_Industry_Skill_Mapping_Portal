01 · CONTEXT & OBJECTIVES
Why map academia to industry skills?
A verified skill inventory is a foundational educational layer for placement readiness and curriculum reform.
CURRICULUM GAP
Many university syllabi lag dynamic hiring prerequisites. Manual curriculum review is time-consuming and difficult to scale across departments.
DECISION SUPPORT
Students, faculty, and placement directors benefit from knowing exact missing competencies and institutional cohort skill shortages in real time.
TECHNICAL CHALLENGE
Competencies vary widely in naming, granularity, taxonomy synonyms, and Bloom's Taxonomy cognitive depths across industries.
PROJECT AIM  |  Develop an AI-assisted workflow that extracts competencies from syllabi & job postings and makes the results available for real-time placement readiness inspection.
KEY OBJECTIVES
  • Prepare curriculum syllabi and job description corpus with verified ground-truth labels.
  • Train and evaluate a rule-enhanced NLP extraction pipeline against a naive keyword baseline.
  • Compute Bloom-weighted student readiness scores (ci ∈ {1.0, 0.5, 0.0}) and classify into actionable tiers.
  • Demonstrate outputs through an interactive 5-role web application with verified benchmarks.

04 · AI METHODOLOGY
Rule-Enhanced NLP with Canonical Taxonomy Linking
Semantic entity extraction and Bloom's Taxonomy cognitive weighting.
INPUT
Syllabus & JD text
›
TOKENIZER
Context token splits
›
TAXONOMY
Boundary regex + alias
›
BLOOM
Cognitive depths 1–6
›
OUTPUT
Normalized vector
DUAL-TIER MATCHING
Strict word-boundary regex patterns (Python|SQL) prevent false positives, backed by TF-IDF cosine similarity for multi-word phrases.
CANONICAL TAXONOMY
Maps 60+ aliases and synonyms into standardized competency entities (e.g., 'Postgres' → 'PostgreSQL') to guarantee deterministic alignment.
BLOOM COGNITIVE RIGOR
Evaluates syllabi by cognitive depth (Level 1 Remember vs Level 4 Analyze). Prevents superficial keyword inflation by requiring application-level outcomes.
OUTPUT: The pipeline computes skill match confidence (ci ∈ {1.0, 0.5, 0.0}) and weighted placement readiness indices.

Risks and how we address them
Ensuring transparency, bias mitigation, and human-in-the-loop governance.
RiskWhat can go wrongMitigation
Vocabulary DriftEmerging frameworks appear unlisted in taxonomyDynamic alias dictionary & TF-IDF semantic similarity fallback
Domain SpecificityAyush informatics terms diverge from generic softwareCustom domain ontology created for SIH26044 problem statement
Token False PositivesShort words ('Go', 'R') trigger false positive matchesStrict regex word boundaries (Go|R) & context filtering
Over-RelianceAutomated scores bias hiring or grading decisions uncheckedHuman-in-the-loop faculty validation & transparent audit trails

Explainable scoring formulas · student data privacy preservation · human-in-the-loop faculty approval · transparent audit trails for all extraction and placement decisions.
